# streamer/ — runtime Godot do Miami WorldStreamer

Cópia instalada a partir de `Miami_2/Miami WorldStreamer/godot/`.

```bash
# a partir de miami3d/
bash "../../Miami WorldStreamer/tools/install_into_miami3d.sh"
```

- Default do jogo: **discrete** (`MnLocationController`)
- Opt-in: `miami/world_mode=stream` em `project.godot`
