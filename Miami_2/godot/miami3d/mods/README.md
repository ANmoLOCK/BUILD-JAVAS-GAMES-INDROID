# mods/ — packs externos (Fase G)

Coloque packs em:

- `res://mods/<id>/` — mods de exemplo versionados no repo
- `user://mods/<id>/` — mods do jogador (sem recompilar APK)

Cada pack precisa de `pack.json` + pastas opcionais `locations/`, `npcs/`, `quests/`, `items/`, `interactions/`, `jobs/`, `schedules/`, `strings/`, `dialogue/`.

Ver `game/phases/g_mods/CRIADORES.md`.
